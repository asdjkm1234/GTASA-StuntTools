# Retired hacks

Expedients that have been replaced by the honest thing. They live on here rather than being deleted, because
the interesting part is the comparison: what the fitted number turned out to be once the real formula was
found, or which assumption the stand-in rule got wrong.

An entry moves here with its original text intact, plus a closing block at the top:

```markdown
**RETIRED <date>.** Replaced by <what>, in <commit / plan link>.
<One paragraph: what the honest version is, and how far the hack was from it.>
```

The row in [`../README.md`](../README.md) stays and points here — a number's history should outlive the
number.
